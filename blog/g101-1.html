叉乘

右手螺旋，我们可以得到垂直于两个向量平面的另一个向量。

判断左右方向：

  • b✖️a叉乘结果为负：如图，b->a是顺时针转的，所以a在b的右边。
  • 如果a✖️b叉乘结果为正：则a在b的左边

判断是否在三角形（多边形）内部：

  • 逆时针构造三个向量：AB，BC，CA

再判断与AP，BP，CP的左右关系。

  • 如果在内部，一定都是在左边。在右边则P在三角形外边。
  • 如果顺时针排布呢，则P始终在这几个向量右边。

统一一下，如果都在同一侧则视为在内部，有不同侧在外部。

1.三维的绕轴旋转

三维对于二维更复杂的是旋转，平移的形式是类似的。

我们绕某个轴旋转的变换矩阵如下，会发现绕y轴旋转的形式有点不一样，最上面的一行是sinθ而不是-sinθ。

我们可以知道任意两个轴叉乘可以得到另一个轴。

我们按xyz顺序的话，任意两个都可以得到另一个对吧，循环对称的性质：

x✖️y得到z轴

y✖️z得到x轴

z✖️x得到y轴

Y 是 z✖️x得到的，并不是x✖️z得到的，所以这就是它矩阵形式不一样的原因。

具体是为什么，你可以展开内容，看看我的理解：

展开折叠内容

对于二维的旋转变换，有这样的关系：

横轴[ cosθ, -sinθ ]

纵轴[ sinθ, cosθ ]

那么，我们可以把发生旋转的平面看成一个二维旋转变换：

  • 1.x✖️y绕z轴---->x：横轴，y：纵轴
  • 2.y✖️z绕x轴---->y：横轴，z：纵轴
  • 3.z✖️x绕y轴---->z：横轴，x：纵轴

我们可以看到横轴变换是带有-sinθ的，纵轴变换带有sinθ。

所以这三种情况拼成矩阵：

  • 1.x✖️y平面旋转，绕z轴：
[ cosθ, -sinθ , 0 ]//x行是横轴带有-sin
[ sinθ,  cosθ , 0  ]//y行是纵轴带有+sin
[   0     , 0 , 1 ]//z行
  • 2.y✖️z平面旋转，绕x轴：
[ 1,     0   , 0]//x行
[ 0, cosθ, -sinθ  ]//y行是横轴带有-sin
[ 0, sinθ ,  cosθ ]//z行是纵轴带有+sin
  • 3.z✖️x平面旋转，绕y轴：
[  sinθ,  0 , cosθ ]//x行是纵轴带有+sin
[ 1,     0     , 0]//y行
[  cosθ, 0 , -sinθ ]//z行是横轴带有-sin

仔细观察矩阵的规律就可以发现，实际上这单纯就是一个循环，只是这时候z行在x行的下面，导致的-sin出现在下面。

把相机的轴向也对应xyz朝向。

怎么把这个过程写成矩阵形式？

先平移，很好写。

把相机空间的轴向掰到xyz的轴向，很难求出来。

但是xyz变得与相机空间一样的旋转方向是很好求的。

比如x轴是（1，0，0）要旋转成其他方向是很好变的。

得到xyz->相机的旋转矩阵，那么这个矩阵就是相机->xyz的逆旋转矩阵。

再对这个矩阵求逆即可！因为旋转矩阵是正交矩阵！！开头说了，所以直接转置一下即可！
